SubmitBlocker

About

SubmitBlocker once it present in the form prevents it to be submitted. It can be used to specify errors caused by multiple fields.

Usage

<Form onSubmit={submitHandler}>
  <p>Set your password</p>
  <TextField
    label="password"
    value={pswrd1}
    onChange={e => setPswrd1(e.target.value)}
    type="password"
    required
  />
  <TextField
    label="password once again"
    value={pswrd2}
    onChange={e => setPswrd2(e.target.value)}
    type="password"
    required
  />
  {
    pswrd1 !== pswrd2 && (
      <SubmitBlocker>
        Passwords do not match
      </SubmitBlocker>
    )
  }
  <Button type="submit">submit</Button>
</Form>

Properties

errorVisibilityMode (optional)

"afterSubmit" | "always"

Specifies the moment when the message is shown.

Default value: errorVisibilityMode of the Form. All values except "afterSubmit" will behave as "always"

className (optional)

string

className prop for div wrapper

inputClassName (optional)

string

className prop for input

style (optional)

CSSProperties

style prop for div wrapper

inputStyle (optional)

CSSProperties

style prop for input

children (optional)

ReactNode

...props

HTMLProps<HTMLInputElement>

All other props will be passed to input element inside SubmitBlocker
