Form

About

Form component behaves like native HTML form element (it uses one inside). It works with spetial components made with usePlainValidation hook.

Usage

<Form onSubmit={submitHandler}>
  {/*
    These textfields should be special
    components made using usePlainValidation
    hook
  */}
  <TextField type="email" required />
  <TextField
    type="number"
    min="0"
    max="100"
    step="10"
  />
  <Button type="submit">submit</Button>
</Form>

Properties

id (optional)

string

className (optional)

string

onSubmit (optional)

SubmitEventHandler<HTMLFormElement>

Submit callback that will be called if submitted form has no invalid fields

onSubmitDeny (optional)

SubmitEventHandler<HTMLFormElement>

Submit callback that will be called on submit decline (due to invalid fields)

errorVisibilityMode (optional)

"afterSubmit" | "afterChange | "afterInput" | "always"

Specifies the moment when the validation message is shown.

Default value: "afterSubmit"

preventFirstInvalidScroll (optional)

boolean

Turns off the behaviour when page scrolls to first invalid field after submit deny

preventFirstInvalidFocus (optional)

boolean

Turns off the behaviour when first invalid field is focused after submit deny
