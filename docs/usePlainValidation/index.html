usePlainValidation

About

usePlainValidation is a hook that will prepare your component for work with HTML forms. It connects to input/textarea/select element inside the component and properly gets the validation status from it.

Usage

export const TextField = ({
  value,
  errorMessage,
  inputProps,
  ...props
}: TextFieldProps) => {
  const {
    controlRef,
    validationMessage
  } = usePlainValidation({
    valueProp: value,
    controlRefProp: inputProps?.ref,
  });

  return (
    <UiTextField
      value={value}
      errorMessage={errorMessage || validationMessage}
      inputProps={{
        ...inputProps,
        ref: controlRef,
      }}
      {...props}
    />
  );
};

Properties

The hook takes object as a an argument. That object shoud contain following properties

defaultMessageConverter (optional)

(message: string) => string

This function will be applied to default (provided by browser) validation error messages. It will not be applied to messages from customMessages or customValidation properties.

customMessages (optional)

{ [keyof ValidityState]: string | (control: FormControl) => string }

For each of the ValidityState properties (except "valid") you can specify your own error message. You can set either the constant string or the function that will return it based on the form control HTML element.

customValidation (optional)

(value: string, control: HTMLElement) => string | undefined

If you need to catch the validation error that is not covered by ValidityState, you can set this function. Each time the function returns truthy string, this string will be used as an error message. After falsy result the default validation mechanism will be used.

errorVisibilityMode (optional)

"afterSubmit" | "afterChange | "afterInput" | "always"

Specifies the moment when the validation message is shown.

Default value: "afterSubmit"

controlRefProp (optional)

Ref<HTMLTextAreaElement | HTMLInputElement | HTMLSelectElement>

React Ref that will be called on the control element at the same time as the returned controlRef.

valueProp (optional)

string

The value prop that you pass to your control element (if your element is controlled)

Return fields

The hook returns an object that contains following fields

validationMessage

string | undefined

The validation message if the field is invalid. Otherwise undefined.

controlRef

Ref<HTMLTextAreaElement | HTMLInputElement | HTMLSelectElement>

React Ref that should be passed to the control element. It should be input, textarea of select, not wrapping element.
